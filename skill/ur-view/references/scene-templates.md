# 建筑与配电站通用场景源码

需要 Three.js 建筑能耗、分层功率分布、配电站机房或电表数字孪生时，直接复制本技能附带的完整模板。不要从业务项目台账、生产截图或历史场景 ZIP 起步。

## 选择模板

| 模板 | 完整源码 | 能力 |
|---|---|---|
| 建筑能耗 | [building](../assets/scene-templates/building/README.md) | 曲面建筑、分层展开、单击跨层与区域、共用计量、功率色阶、历史 |
| 配电站 | [power-station](../assets/scene-templates/power-station/README.md) | 柜列、母线、五金、程序材质与反射、仪表拾取、聚焦巡航、详情趋势 |

两套目录均包含源码、本地依赖、许可证、配置、打包工具和测试，可独立复制后运行。不依赖业务仓库、不包含项目名称、生产地址、真实台账或设备凭证。模板的布局、柜列和锚点数量只是可替换的图形示例，不能作为现场资料引用。

## 接入步骤

1. 整体复制所选目录；先独立查看模型与交互。未绑定或未配置物模型时应为空数据，不启用模拟回退。
2. 查目标环境文档，核验授权项目的设备清单、物模型属性、单位和上报周期；数据来源必须可追溯到现场记录。
3. 按模板 README 配置名称、范围、字段和倍率。只在计量关系确认后配置进线与范围汇总；未知上下级时分别显示，不将进线和馈电混加。
4. 按模板的 `package.py` 打包，复制/上传运行 ZIP。依赖为本地 Three.js r128 与 `ur-scene` SDK，不另加大型框架、在线 HDR 或高斯泼溅。
5. 将返回的 `entryUrl` 配入 EmbedPage，宿主通过 `meter/<本地锚点ID>` 绑定真实产品与设备。锚点是模型位置标识，不要求等于设备名；产品与设备组合才是唯一身份。
6. 草稿验收通过后发布，再核对列表封面与发布页面。产品、项目、大屏、资产编号及地址从目标环境取得，不沿用其他场景取值。

## 数据与失效规则

- 默认没有任何生产绑定、真实属性映射或已确认汇总关系；无绑定、字段未配置、缺失、过期和请求失败应明确区分。
- 凭证仅由宿主持有。场景请求全部通过 SDK，限定已绑定设备；不扫描整产品历史。
- 重复握手保留有效状态，改绑或解绑清空旧记录；在途旧请求不得把旧设备读数写到新设备上。
- 设备去重用 `productID + deviceName`。同设备出现在多个区域或楼层，显示可以复用，求和不能重复；不得按面积虚构房间功率。
- 零功率有效，负值保留；历史按30分钟时间点对齐，只取该点以前且未过期的记录，缺成员留断点，不补零。
- 字段/单位与有效期须按物模型核对；不能因为列表为空就判定属性不存在，也不能用当前时间替代缺失的上报时间。

## 发布与性能检查

组件位置与尺寸应落在画布内；不要继承超出画布的宽高导致裁边。场景 ZIP 各不超过2 MB，首次显示主体后再补充细节，接口慢不应阻止操作镜头。

默认像素比上限1.5、单主要阴影光源；共享几何与材质，小贴图/反射资源随包提供。分别记录宿主、iframe主体/细节、数据就绪和旋转帧率，记录视口、网络、缓存及GPU类型。软件光栅测试不替代硬件30FPS验收。

修改上传资产后重新发布；同资产路径的 JS 可能被浏览器缓存，优先新建版本资产或明确资源版本。删除旧资产前检查发布引用。只整理模板时不需要登录生产或发布大屏。

## 模板维护与分发

模板维护源为技能仓库的 `ur-view/assets/scene-templates`，同步到 CLI 的同名内部目录与项目技能入口。只同步新增模板、指南与索引段落，不能整目录覆盖已有技能内容。不得将业务配置、认证存储、node_modules、.temp、截图日志或生成的旧ZIP混入模板源。

调用模板自带的数据与浏览器测试，再执行 `assets/scene-templates/validate.py` 检查独立打包。CLI 验证应覆盖 release、platform及npm分发的完整文件字节，不能只检查 Markdown 文件存在。测试夹具只存在测试目录或测试脚本，不加入运行 ZIP。

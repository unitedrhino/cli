# system/user/self/accessToken

> 该 group 共 5 个端点。

- `POST /api/v1/system/user/self/access-token/create` [all] 创建访问令牌
- `POST /api/v1/system/user/self/access-token/delete` [all] 删除访问令牌
- `POST /api/v1/system/user/self/access-token/get-list` [all] 获取访问令牌列表
- `POST /api/v1/system/user/self/access-token/get-one` [all] 获取访问令牌详情
- `POST /api/v1/system/user/self/access-token/update` [all] 更新访问令牌

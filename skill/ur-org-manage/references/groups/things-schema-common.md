# things/schema/common

> 该 group 共 8 个端点。

- `POST /api/v1/things/schema/common/batch-export` [admin] 批量导出通用物模型
- `POST /api/v1/things/schema/common/batch-import` [admin] 批量导入通用物模型
- `POST /api/v1/things/schema/common/create` [admin] 新增通用物模型
- `POST /api/v1/things/schema/common/delete` [admin] 删除通用物模型
- `POST /api/v1/things/schema/common/get-list` [admin] 获取通用物模型列表
- `POST /api/v1/things/schema/common/init` [admin] 初始化通用物模型
- `POST /api/v1/things/schema/common/mock-gen` [admin] 从参数生成物模型定义
- `POST /api/v1/things/schema/common/update` [admin] 更新通用物模型

# Watcher 圆屏 UI 与保留绑定换网

适用于 TASK-143 接口及实现；发布前先确认目标固件和小程序已包含该能力。
开发分支测试通过不等于设备已经升级，未部署时不得向用户承诺可以换网。
环境、设备、串口和受控备份位置从当前任务与部署环境说明读取，不沿用历史设备。

## 界面与输入所有权

- 配网成功页要同时检查板级输入分发和菜单模型：不能只在模型中提供返回按钮，
  板级却仍用整个独占流程标志拦截触摸或把点击当取消。可靠保存后的完成动作应结束
  独占启动并恢复正常联网（Watcher 在独占配网启动中重启），不能清密钥或回滚已保存网络。
  正常启动和 OTA 重启不自动弹出历史成功页，否则 Visibility 交互锁会让聊天入口静默无效，
  表现为 listening_timeout 而没有 sessionCreate。保留 BLE 查询所需的历史记录，不清 NVS 规避。
  启动恢复快照先于状态栏网络刷新，按请求 ID 仅抑制本次普通启动的旧成功记录；
  独占配网、新请求、存储异常和失败恢复仍显示。历史成功页若已展示，完成动作只回主页。
  回归覆盖生产 UpdateNetworkPage、启动/刷新竞态及 OTA 后不操作菜单即可开始语音；
  重复终态不得重新打开用户已退出的结果页。
  BLE 结果重查窗口保留自动结束兜底，显式完成允许提前退出；覆盖重复点击、旧触点、
  睡眠首次触摸及未提交状态不能提前结束。主机测试须执行真实板级分发，不只测菜单。

- Watcher 是 412×412 圆屏，关键文本与焦点限制在中央安全区域；矩形截图不证明圆屏可读。
- 主页/对话单击开始或打断后监听，双击拍照，长按 2 秒进入菜单并关闭语音。
  菜单中滚轮仅移动焦点，单击确认，长按返回；不得再触发音量快捷键或拍照。
- 恢复出厂放在电源确认页，默认取消。USB 供电显示重启，电池供电显示关机；
  不保留持续长按自动擦除 NVS 的暗路径。
- 菜单向左滑返回上一层，主菜单回主页；主页无返回动作，右滑不代替返回。
  复用页面代次和忙状态保护，唤醒首段接触不执行；活动换网不取消，保存结果走既有完成入口。
  `test_watcher_swipe_back.py` 验证层级与安全，真实LVGL指针回放验证识别及回调；实屏另验。
- 网络、相机、音频任务只投递事件，LVGL 显示任务操作对象。保持页面控制器唯一，
  状态栏可复用 top layer，不为每页重建驱动。重复终态不得抢焦点或重开已退出页面。
- 测试固件可用 `ur_hw_test press / double-press / long-press / next / previous` 注入输入；
  必须走物理按键共用的板级分发，禁止直接调用聊天函数冒充按键 E2E。
  ACK 仅表示排队；长按注入不验证触点持续 2 秒，屏幕实际显示仍需另验。
- 活动对话、相机 worker 和换网禁止息屏；唤醒输入不透传业务动作。菜单空闲 30 秒
  返回主页，但正在配网不能因此退出。长字幕分区可滚动；预览不被普通状态消息清除。
- 网络结果页显示非敏感错误原因；存储恢复失败只能重启重试，不能绕过恢复继续联网。
- 动态字体替换必须覆盖未激活页面和 top layer；LVGL 样式只保存字体裸指针，旧字体
  所有者释放前同步更新全部页面。只更新当前屏会在稍后打开菜单时触发悬空指针崩溃。

### 串口截图与滚轮回归

菜单点按无响应时，先区分串口板级输入回放与真实触摸采样；前者通过不能关闭触屏缺陷。
包含触摸诊断的测试固件可用 `ur_hw_test state` 读取 `[UR_TOUCH]`，比较点按前后的累计差值：
`available/reads/errors` 分别表示驱动接入、采样运行和通信失败；`contacts/wakes`
区分新接触与仅唤醒；`events/busy/stale` 区分触摸动作已消费、资源占用拒绝和旧页面代次；
`down` 表示仍未抬手。读取正常但没有新接触，应继续检查实际触点；接触增加但没有动作消费，
检查 LVGL 命中、拖动和回调；动作消费增加后仍不执行，检查门禁与页面状态。
`events` 同时包含条目点击与左滑返回，不能直接把累计差值当作某一种动作成功。
计数不保存坐标、正文或凭据，仅在测试开关下存在，不新增平台接口。
旧固件不输出该行时先核对构建/版本，不能把无诊断字段判作触摸驱动失效。
`test_watcher_touch_diagnostics.py` 回放生产采样回调及消费片段，正式/测试开关分别编译，
覆盖仅唤醒、通信故障后完整抬手、占用和旧页面；这些用例不代替真实触屏坐标、滚动和显示验收。

`test_watcher_menu_layout.py` 进一步链接实际LVGL、内置字体和生产页面管理器，
从按下/抬手采样经真实命中、手势、回调和菜单消费执行十轮，不直接发送点击事件。
覆盖主页入口、网络/音量/电源子页及返回、跨页状态层、仅唤醒、忙状态与通信故障。
用“回调后丢弃入队”负例确认菜单不动会被检出；该注入不是现场缺陷已复现。
硬件读数、应用队列和基类对象创建仍是边界替身，不证明任务并发、物理坐标或LCD可读。
在依赖已准备的SaaS任务仓库运行：

```bash
bash shell/resource-guard.sh run --profile heavy -- \
  python3 -m unittest discover -s firmware/watcher/scripts/tests \
  -p test_watcher_menu_layout.py -v
```

包含新调试入口的测试固件可用 `ur_hw_test snapshot` 取得真实 LVGL 合成 JPEG，
不能用相机照片或重绘示意图代替截图。active screen 不含独立 top/system layer，
必须一起捕获并核验层大小、像素格式/alpha 和行步长；任意层失败不能返回残缺图冒充成功。
截图包含字幕或预览时属于私有验收数据，不入库，不经公共图片服务上传。

在直连开发机独占串口，运行：

截图、语音及拍照复测脚本在配置/读取串口前使用非阻塞排他锁，占用时立即失败，
不排空日志或发送设备命令。锁只协调遵守该约定的程序，仍须关闭其他串口终端。
新增取证入口沿用同一串口文件锁；用真实伪终端持锁并启动生产脚本，验证拒绝占用且
没有写入，而非只检查源码包含锁调用。释放串口后再开始下一阶段，不因暂时无日志启动第二个消费者。

```bash
python3 firmware/watcher/scripts/run_watcher_ui_probe.py \
  --port '<当前设备串口>' --output '<受限目录>/screen.jpg' --verify-knob
```

不加 `--verify-knob` 只截图；增加该选项会结束语音并验证菜单焦点与主页音量，
要求初始主页，不自动退出配网或危险确认页。状态回读须看到输入队列清空及实际音量变化，
不能以 ACK 代替操作生效；结束恢复原音量。主页/对话旋钮调音量，菜单旋钮移动焦点，
音量子页调整音量；长字幕用触屏滚动，不能再次截走主页旋钮。
Watcher 音量约定为左滚增加、右滚减少，每格 5%，范围 0–100%；板级回读实际值后
显示百分比短提示 2 秒，边界滚动也须反馈。Next 对应右滚，但菜单焦点不反转；
音量与亮度编辑页都左增右减，触屏“减小/增大”仍保持按钮文字语义，菜单焦点方向不反转。
用 `test_watcher_volume_feedback.py` 回放真实板级函数，配合菜单模型覆盖方向、
限值、触摸和实际回读；截图需在提示有效期内取得，不能用变化后的音量日志证明提示可见。
若怀疑截图某控件消失，先核对原始图片及控件区域像素，再复测即时/静置状态；
不要只凭一次视觉误读修改显示代码。截图异步于状态回读，不能把上一条短提示当作最终设置值。
串口截图校验传输 ID、连续偏移、大小、CRC 和 JPEG；拒绝缺片、重复、混帧，
只保存完整图片。截图证明软件合成，不证明 LCD 实际显示、触摸校准或扬声器声音。
回归入口为 `test_display_snapshot.py`、`test_watcher_ui_runtime.py` 和菜单状态机测试；
还须在真机核验截图包含状态栏、状态与菜单不重叠、快速旋转以及对话播放期间不卡顿。

### 截图崩溃、串口分片与跨页遮挡排查

- 字体名中的字号不是实际行高。先从板型 CMake 选择和真实字体资源核对 `line_height`，
  再检查文字槽高度、内边距与圆屏安全区；Watcher 内置 30px 字体实际行高 43px，
  35px 状态栏及 40px 菜单文字槽会裁字。不要只把不同矩形排开就宣称可读。
  空角色标签须隐藏，不能以空字符串仍占一行挤压另一角色；长字幕保留触屏滚动。
  首段回复及停留尾部时的增量跟随，用户上滑阅读则保留位置；预览结束恢复最新回复。
  `test_watcher_subtitle_viewport.py` 编译执行生产视口函数与真实跟随表达式，覆盖空角色、
  首段/增量、人工阅读和预览切换并连续运行十次；几何用例先验证旧实现失败。
  最后使用本次固件截图及实际圆屏确认状态文字、菜单和长回复，主机替身不证明像素可见。
- 多行结果标题必须按真实排版高度安排列表，不能沿用单行标题的固定起点。
  `test_watcher_menu_layout.py` 链接实际 LVGL 与内置字体，执行生产页面创建和渲染；
  对绑定完成、换网完成、超时、取消及存储失败连续十次检查标题/列表不重叠、
  列表底边仍在圆屏安全区。缺少受管理依赖时明确跳过，不将跳过当作布局已验证。
  同一真实LVGL用例还执行生产字幕布局、视口函数和跟随表达式：用多屏汉字长文
  检查首段滚到末尾、上滑位置不被后续增量改变、新用户字幕回顶及预览结束恢复尾部。
  这补足滚动调用替身的布局边界，但仍不能代替物理触屏拖动及LCD现场可读性。
  网络事务页的硬件验收仍需真实流程截图，不能为了采图改写设备已保存网络。
- 截图命令本身也须验收栈预算。若日志停在页面渲染开始，未到渲染结束便崩溃，
  先记录调用任务的栈余量和阶段，不因回溯落在调度器就直接改 FreeRTOS。
  Watcher 已复现默认 4KB 控制台栈不足：测试构建预留 12KB 后连续截图通过，
  正式构建保持原预算且不开放测试入口。换字体、页面或 LVGL 后仍需重新测余量。
- RGB565 字节序按 LVGL 输出和 JPEG 编码器合同核对；当前 RGB565_LE 入口不额外交换字节。
  用确定性红绿蓝像素执行生产捕获函数，不能只靠 JPEG 魔数验证颜色正确。
- 串口可在 END 前缀或传输 ID 中间分片；必须收齐完整结束行再校验并保存图片。
  对结束记录逐字节切分测试，覆盖超时、缺片、重复及崩溃标记；失败不保存半张图。
- 独立 top layer 会跨页面保留。主页主题与固定深色菜单不同，切页和换主题时都要重设
  状态栏配色；主页底部提示层在菜单隐藏、回主页恢复，避免时钟和通知压住菜单列表。
  回归真实主页、对话、菜单首尾项、预览和网络结果页；菜单聚焦末项时也须截图。
  同步检查活动/隐藏页字体生命周期，入口为 `test_watcher_font_lifetime.py`。

### SPD2010 在 IDF 6 下的纯读兼容

若启动日志出现 `i2c transmit buffer or size invalid`、SPD2010 `Read version failed`，
先检查 LCD I²C 读入口，不要直接判定接线错误。该驱动先单独写寄存器地址，
随后必须以 `lcd_cmd=-1` 纯读取；配置为零命令位、无控制阶段却传 `0`，会让 IDF 6
尝试零长度 `transmit_receive` 并返回参数错误。不要通过增加命令位发送额外寄存器字节。
Watcher 使用 `prepare_touch_i2c.py` 在构建目录生成单点适配，CMake 只替换该组件编译输入，
不修改受管理依赖；锚点或源数量变化须停止审查。`test_touch_i2c.py` 执行读调用表达式，
验证旧入口失败、新入口十次通过及依赖漂移；这仅证明调用合同，不能替代真实 I²C 验收。
真机还需核验驱动初始化成功、坐标/滚动、首页触摸入口及唤醒误触保护，不能只凭 OTA 成功。

## 官方客户端权限与配网绑定

当前换网仅涉及设备与小程序：不新增云端网络签名接口或 E6，保留 E5 v2。
官方小程序从既有设备查询取得真实项目，查询当前账号、项目拥有者及明确项目管理授权；
普通读写成员不放行，权限查询失败不发送凭据。此检查属于官方客户端策略，
不是 BLE 密码学鉴权；物理限时窗口中不能宣称阻止其他 BLE 客户端。手机需联网查询既有权限，
设备可离线；不下发 configureNetwork、不创建绑定 Token 来执行换网。

网络菜单分开“更换 Wi-Fi”和“配网并绑定”。后者二次确认默认取消，
独占启动复用 SDK Token 流程，候选不提前写正式列表；收到 `appBindToken code=200`
且仍有 IP 后提交网络。该回执只证明 Token 与设备关联，小程序随后调用绑定接口才完成归属。
提交前异常重启或 SDK 失败保留旧网络；手机后续绑定失败不会撤销已保存的新网络，
也不主动清密钥或解绑。云端绑定与本地保存不是分布式事务，云端已经成功后本地故障
不能自动回滚绑定；测试必须分别核对 Token 回执、手机绑定接口结果与 Wi-Fi 保存。
首页显式触摸菜单、音量/亮度触摸增减继续使用原页面代次、忙状态和唤醒保护。
以上新增能力仍需目标固件、Android/iOS 与真实断电验收，不拿旧固件结果代替。

回归增加双端 `network-permission-runtime.test.cjs`（拥有者、管理员、普通成员、
其他项目/用户、查询失败），保留 E2/E4 日志脱敏；不再运行撤销的签名向量测试。
`test_ur_network_ble.py` 执行实际绑定入口和候选路径，覆盖 SDK 失败、IP 丢失、
读取/提交失败及成功；`test_ur_network_transaction.py` 覆盖绑定受控启动和冷启动恢复。

## 本地换网事务与可选在线入口

换网保留正式 Wi-Fi 列表、DeviceSecret、所属项目和绑定；候选配置独立持久化。
BLE 配网独立启动，不与正常 WifiManager 并行初始化。OTA/相机忙时拒绝入口，
进入换网先关闭语音。在线行为先回执受理，再显示默认取消的物理确认页；离线可以本地进入。

| 合同 | 内容 |
|---|---|
| `configureNetwork` | 可选在线唤起行为，输入 `requestId` 为 16 位十六进制字符串，输出布尔 `Result`；本地菜单不依赖该行为 |
| 本地闭环 | 不新增状态属性、不等 MQTT 回执、不修改后端；已有 `networkConfigStatus` 不再作为前提，也不自动删除 |
| 阶段 | 0 空闲、1 已准备、2 BLE 等待、3 候选连接、6 提交、7 已保存、8 失败、9 待物理确认；4/5 为旧流程保留值 |
| 错误 | 0 无、1 重启中断、2 超时、3 取消、4 鉴权（旧流程保留）、5 网络、6 存储 |

BLE 等待最多 180 秒；取得 IP 后还须确认实际关联 SSID 与候选一致，
保存提交意图、写入并回读正式列表、持久化成功终态，然后才发送标准联网成功通知。
GATT 写完成、取得 IP 或阶段受理均不能直接显示成功。云端不可达不撤销已保存的新网络，
应单独显示云端离线。换网不清密钥、不动态注册；提交前取消、超时、异常启动恢复旧配置。
正式配置写入中断需先完成恢复并回读，恢复不确定时停止普通联网，不能丢失旧网络。

仅使用可选在线入口时，通过既有 API 查询行为、仅创建缺项、回读确认；冲突停止，不覆盖其他能力。
在包含 TASK-143 工具的 SaaS 仓库根目录：

```bash
python3 shell/converge-watcher-network.py --check \
  --expected-base-url '<当前环境地址>' --expected-tenant-code '<当前组织编码>'
# 目标及环境门禁通过、写操作获授权后，才将 --check 改为 --apply。
python3 shell/test-converge-watcher-network.py
```

工具当前限定 Product 8；其他产品不能照抄执行，应先核验并调整目标合同与测试。
`--check` 返回 1 表示缺项，2 表示检查失败；`--apply` 部分失败可幂等重跑，但不得忽略合同冲突。

## BLE 与小程序边界

小程序网络入口统一位于设备设置的“Wi-Fi 管理”，不要把 configureNetwork 渲染成普通
物模型按钮。复用“准备设备 → 选择 Wi-Fi → 连接网络”引导，准备页必须保留已经授权的
changeNetwork 会话；失效时返回设置，不调用 startSession 降级成首次绑定。
网络保存成功后显示“Wi-Fi 已更新，设备正在恢复在线”，不等待账号绑定或云端在线来判换网。

首次绑定须区分三个结果：Wi-Fi 已保存、Token 关联成功、手机绑定接口成功。
SDK 收到 Token 后不能提前主动关闭 GATT，应等最终 E3 通知后统一释放蓝牙栈。
临时 MQTT 退出、设备重启期间，绑定接口可能明确返回设备离线码 2000003：
仅对这个明确失败在当前会话/身份/Token 内有界等待重试；取消后不再发请求，
其他业务错误或网络结果不明不盲目重发。Watcher 当前等待上限 90 秒、间隔 2 秒。
每个 ACK 等待器都须能在写入失败时精确取消，及时处理拒绝，避免孤立 Promise 错误。
扫描监听先于发现启动；启停串行、每轮去重、失败后释放本次连接，覆盖连续十轮重试。
自动测试不能替代 Android/iOS 对再次扫描、断连恢复及最终绑定结果的现场验收。

沿用 FFF0/FFE1/FFE3。换网能力通知 E5 为 15 字节：`e5 00 0c 02 01 stage error`
后接 8 字节请求 ID。具体编码以固件及双端解析器为准；旧固件无能力时提示升级，
不能回退到首次绑定。这里扩展版本 2 是本地保存语义，不能将旧版本 1 的云端确认当作同一合同。
`changeNetwork` 必须在申请绑定 Token 之前分流。手机写入 E5 是读取日志、设备以 E4 回复；
设备通知 E5 才是换网能力，不能混淆方向。

WiFi 配网广播的版本是完整字节 `02`，不能套用标准蓝牙模式的高四位版本编码。
微信厂商数据包含两字节 Company ID；BlueZ 的 ManufacturerData 已以 Company ID 为键，
对应值是从版本开始的 17 字节正文。协议测试应回放真实结构，不能只锁定源码正则。

GATT 回调栈可能只有数 KB；候选事务及 NVS 校验会叠加多个网络快照，不能直接在回调执行。
回调只校验并复制到有界信箱，由已有换网 worker 持久化和设置临时 STA，完成后才通知受理。
测试须断言回调零持久化、提前 E3 拒绝、队列满、保存/驱动失败及密码副本清零；
主机测试没有 MCU 栈限制，仍须用同步串口捕获真实 E2 写入，区分 ATT 错误与 BTC_TASK 栈溢出。

- 同产品可能有多台设备；广播只用于筛选，写 Wi-Fi 前必须通过 GATT 核对所选 DeviceName。
  自动发现仅在明确的身份不匹配时断开并检查下一候选；连接、能力或断开失败立即停止。
  用户明确选择的错误设备不能自动换成另一台，错误设备不得收到密码。
- 候选指令前后核对连接代次、会话代次、请求 ID；取消后的迟到通知/HTTP 回复不能推进新会话。
- Wi-Fi 页面卸载后不得由异步初始化重新订阅、挂监听或写状态；向进度页主动交接则保留会话。
- 提示 2.4GHz 并保留手动输入；不要使用“长按 5 秒、灯快闪”的旧 Watcher 文案。
- 小程序须核对当前设备、连接代次、有效请求，以及标准 E2 的连接成功和目标 SSID；
  E2 本身没有请求 ID，不能只凭一条迟到成功包完成流程。
- 保存后保留 30 秒 BLE 结果窗口。等待结果异常时最多重连原设备一次，
  仅在同一请求已提交后发送 E3 只读查询，不重发模式/密码/Token；页面内同请求重试同样只读。
  窗口结束、结果未提交或重查失败保持“未确认”，不能凭断开或历史在线宣称成功。
  整个换网路径不得调用绑定/解绑、创建 Token 或修改项目归属接口。

## 最近网络与构建适配

MQTT 重连验收必须等待本次订阅的 SUBACK，而不是只查询 topic 是否存在于 SDK 缓存。
Watcher SDK 的 IsSubReady 在重连后仍可能命中旧 topic；使用 Subscribe 返回的 packet ID
匹配全局订阅确认事件。NACK/超时锁存失败，迟到的其他 ID 和重复成功不能将失败改为成功。
验证入口 `test_ur_subscription_ack.py` 回放生产等待器与回调；真机分别验证冷启动与断连
恢复后的会话，不能仅凭“subscriptions restored”日志宣称下行可用，也不将订阅修正视为
所有 sessionCreated 超时的既定根因。

- 保留最近成功使用的 10 个 SSID；同名更新，不保留同名不同密码的多条记录。
- 正常取得 IP 才更新独立排序 blob，只存 SSID；重复连接首项不写 Flash。
  候选提交按最近顺序保留旧网络，第十一项淘汰最久未成功使用项；失败不淘汰旧网。
- 排序损坏不能隐藏有效凭据或触发解绑，回退原槽位顺序；提交中断必须恢复旧快照及顺序。
- 连接正常时不主动切网；断开后扫描已保存网络，最近成功网络优先，同 SSID 保留信号排序。
- 多网络必须完整扫描后排序；旧缓存信道可见旧 AP 时，驱动可能不再全扫，导致新热点永远不进入排序。
  回归应执行真实生成的扫描函数，覆盖跨信道新热点与单网络快速扫描；不要仅测试排序数组。
  BLE 提交后还须核对重启后的实际 SSID/IP，再确认 MQTT 恢复，禁止仅凭平台在线判换网通过。
  可复测命令：`python3 firmware/watcher/scripts/run_ur_network_e2e.py --product-id <产品ID> --device-name <设备名> --mac <蓝牙MAC> --verify-boot-log <本次串口日志> --expected-ssid <新网络名>`。
  该模式只读日志，不操作蓝牙；要求最近启动中的网络、IP、指定设备 MQTT 和属性回执齐全。
  它不替代 BLE 请求关联、密钥/绑定回读或手机验收。
  已保存网络暂不可用时持续重试，不因启动 60 秒超时自动停止 STA 并开启热点。
- Watcher 构建在 build 内生成扫描源副本，适配多网络全信道扫描与最近网络排序，继续使用原驱动连接和重试；
  不手改 managed_components。生成器锚点漂移必须阻断构建并审查，不能静默退回信号优先。

## 可复测验收

在直连 Linux 上使用仓库 `firmware/watcher/scripts/run_ur_network_e2e.py`：

```bash
python3 firmware/watcher/scripts/run_ur_network_e2e.py \
  --product-id '<产品ID>' --device-name '<设备名>' --mac '<广播MAC>'
```

先从设备菜单开启换网窗口。默认只读身份和能力；只有明确授权写候选时加
`--provision-stdin`，通过受控 stdin 输入 `ssid/password` JSON，不把密码写入参数。
需要 Linux 系统 dbus/gi 和 BlueZ；失败不自动重发凭据，断开或脚本观察超时不是成功。
脚本回放单测为 `test_network_e2e_runner.py`，不替代真实 GATT 与手机验收。

检查热点实际广播频段，不只看设置页的“任何可用频率”。Linux 先执行
`nmcli device wifi rescan ssid '<目标SSID>'`，确认无权限/扫描错误并等待扫描完成后，
再查看 `nmcli -f SSID,FREQ device wifi list --rescan no`。SSH 会话可能无扫描权限；
`list --rescan yes` 即使退出码为 0 也可能只返回缓存。无法确认新扫描时应标记未知，
不能据缓存未列出热点要求现场反复修改或阻止已授权的真实设备配网测试。
Watcher 需要 2.4GHz；只有新扫描证实同名热点仅在 5GHz 时才据此要求调整。
其他设备成功连接不证明 Watcher 兼容该频段，设备连接超时也不能直接推断密码错误。
错误密码用例可对已有 SSID 写入明确错误的候选密码，再等待设备完整超时窗口；
必须同时核验重启后原网络恢复、MQTT 在线和身份/绑定未变。脚本返回断开只表示
未取得成功确认，不能单独证明恢复成功。

先记录固件 SHA/版本、手机系统、小程序构建配置、物模型合同及现有绑定；密钥比较仅在
受控工具内执行，不把明文或完整认证响应写日志。默认配置或占位密钥构建禁止刷写/上传。

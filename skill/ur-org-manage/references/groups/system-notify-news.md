# system/notify/news

> 该 group 共 5 个端点。

- `POST /api/v1/system/notify/news/create` [platform] 创建资讯
- `POST /api/v1/system/notify/news/delete` [platform] 删除资讯
- `POST /api/v1/system/notify/news/info` [platform] 获取资讯详情
- `POST /api/v1/system/notify/news/list` [platform] 获取资讯列表
- `POST /api/v1/system/notify/news/update` [platform] 更新资讯

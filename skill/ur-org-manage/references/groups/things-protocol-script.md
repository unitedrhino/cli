# things/protocol/script

> 该 group 共 8 个端点。

- `POST /api/v1/things/protocol/script/batch-export` [admin] 批量导出协议脚本
- `POST /api/v1/things/protocol/script/batch-import` [admin] 批量导入协议脚本
- `POST /api/v1/things/protocol/script/create` [admin] 新增协议脚本
- `POST /api/v1/things/protocol/script/debug` [admin] 协议脚本调试
- `POST /api/v1/things/protocol/script/delete` [admin] 删除协议脚本
- `POST /api/v1/things/protocol/script/get-list` [admin] 获取协议脚本列表
- `POST /api/v1/things/protocol/script/get-one` [admin] 获取协议脚本详情
- `POST /api/v1/things/protocol/script/update` [admin] 更新协议脚本

# system/notify/template

> 该 group 共 5 个端点。

- `POST /api/v1/system/notify/template/create` [platform] 添加通知模版
- `POST /api/v1/system/notify/template/delete` [platform] 删除通知模版
- `POST /api/v1/system/notify/template/get-list` [platform] 获取通知模版列表
- `POST /api/v1/system/notify/template/get-one` [platform] 获取通知模版详情
- `POST /api/v1/system/notify/template/update` [platform] 更新通知模版

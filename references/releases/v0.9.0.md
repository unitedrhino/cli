# v0.9.0 更新说明

## 业务摘要

AI 可直接查询大屏组件目录和平台内置图元，核对图形来源后制作电力一次图，并按区域设备逐表绑定，接入能源配电图。CLI、操作说明、一次图案例和 Skills 同步交付。

## 新增命令

```bash
ur view component search --keyword 连线 --json
ur view component get-one --key TextCommon --json
ur view builtin-image search --keyword 圆形 --category electric --size 10 --json
ur view builtin-image get-one --id bi-electric-0952 --json
```

组件目录离线可用，包含注册 key、渲染框架与 IoT 支持信息。图元搜索复用平台只读接口，支持分类、标签、格式、确认状态和分页，详情返回稳定来源 ID、说明、URL 与尺寸。JSON 使用 code/msg/data，业务失败保留错误码并返回非零退出码。

## 技术与技能更新

- 更新组件快照至 2026-11-05，保留存量一次图 ConnectLine，修复动态语言标题和预置组件引用的快照解析。
- 同步开源 Skills、CLI 随包 Skills、独立 Skills ZIP 和开发助手整理副本，补全参数、输出、错误及绘图接入流程。
- 画布中的设备使用 Image，文字和读数使用 TextCommon，连线按实际组件配置生成。图元保存来源 ID，设备独立绑定，无数据以 `--` 表示，推测参数标为待核对。

## 升级与使用

```bash
ur upgrade --version v0.9.0
ur --version
ur view component get-one --key ConnectLine --json
ur check --json
ur view builtin-image get-one --id bi-electric-0952 --json
```

升级同步随包 Skills 和已识别的客户端副本，重开 AI 会话加载新指引。组件目录为快照，目标平台须已提供对应组件。在线图元接口需要已有企业访问权限，调用使用 app-id=200。

按[搜索说明](../../skill/ur-view/references/component-search.md)完成搜索、看图核对、画布生成、设备绑定和能源区域接入。普通生成默认保存草稿，发布与区域配置修改按用户授权执行。

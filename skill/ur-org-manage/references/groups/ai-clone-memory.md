# ai/clone/memory

> 该 group 共 11 个端点。

- `POST /api/v1/ai/clone/memory/archives/get-list` [admin] 获取归档记录列表
- `POST /api/v1/ai/clone/memory/compact` [admin] 压缩记忆
- `POST /api/v1/ai/clone/memory/create` [admin] 添加记忆
- `POST /api/v1/ai/clone/memory/delete` [admin] 删除记忆
- `POST /api/v1/ai/clone/memory/dream-runs/get-list` [admin] 获取 Dream 运行记录列表
- `POST /api/v1/ai/clone/memory/dream/run` [admin] 手动触发 Dream 整理
- `POST /api/v1/ai/clone/memory/entities/get-list` [admin] 获取记忆实体列表
- `POST /api/v1/ai/clone/memory/profile/get-one` [admin] 获取记忆画像
- `POST /api/v1/ai/clone/memory/records/get-list` [admin] 获取记忆记录列表
- `POST /api/v1/ai/clone/memory/search` [admin] 搜索记忆
- `POST /api/v1/ai/clone/memory/traces/get-list` [admin] 获取召回轨迹列表

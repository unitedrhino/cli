## 错误码速查表

### HTTP 状态码

| 状态码 | 含义 | 处理建议 |
|--------|------|----------|
| 200 | 成功 | 检查 data 字段 |
| 400 | 参数错误 | 检查请求参数格式和类型 |
| 401 | 认证失败 | JWT 无效或过期，检查 accessKey/Secret |
| 403 | 权限不足 | 需要更高权限，检查 x-auth-type |
| 500 | 服务器错误 | 联系管理员，检查服务日志 |

### 业务错误码（code 字段）

| 错误码 | 名称 | 说明 | 常见原因 |
|--------|------|------|----------|
| `200` | 成功 | 请求处理成功 | - |
| `100000` | 系统错误 | 内部异常 | 联系管理员查看日志 |
| `100001` | 参数错误 | 请求参数不合法 | 必填字段缺失、格式错误、类型不匹配 |
| `100002` | 数据不存在 | 请求的资源不存在 | ID 错误、已删除、无权限访问 |
| `100003` | 权限不足 | 用户权限不够 | 角色权限不足、数据权限不足 |
| `100004` | 数据已存在 | 唯一约束冲突 | 名称/编码重复 |
| `100005` | 未授权 | Token 无效 | Token 过期、被撤销、格式错误 |
| `100006` | 业务校验失败 | 业务规则校验不通过 | 状态流转错误、前置条件不满足 |
| `1000007` | 登录失效 | Session 过期 | 重新登录 |

### 登录相关错误

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| 账号或密码错误 | 密码不正确 | 检查 pwdType 和密码 |
| 验证码错误 | 短信/图片验证码错误 | 重新获取验证码 |
| 该企业未绑定该应用，无法登录 | 租户未开通该 App | 联系平台管理员绑定应用 |
| 您没有权限访问该应用 | 用户无租户绑定该 App | 切换租户或联系管理员 |
| 未加入租户 | client 应用自动注册失败 | 检查租户配置 |

### 设备相关错误

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| 设备不存在 | deviceName 错误 | 查询设备列表确认 |
| 产品不存在 | productID 错误 | 查询产品列表确认 |
| 属性不存在 | 物模型标识符不匹配 | 查询物模型确认 identifier |
| 设备离线 | isOnline=2 | 等待设备上线或检查网络 |

### JWT 相关错误

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| 认证失败 | JWT 格式错误 | 检查 Header 格式：`Bearer <jwt>` |
| userID 格式错误 | userID 是数字类型 | 改为字符串：`"userID": "12345"` |
| Token 过期 | exp 时间已过 | 重新生成 JWT |
| 签名验证失败 | Secret 错误 | 确认 accessSecret 正确 |

### 常见参数错误示例

```json
// ❌ 错误：枚举值用了数字
{"status": 1}

// ✅ 正确：枚举值用字符串
{"status": "1"}

// ❌ 错误：deviceName 用了显示名称
{"deviceName": "一楼开关"}

// ✅ 正确：deviceName 用设备ID
{"deviceName": "switch_001"}

// ❌ 错误：分页从 0 开始
{"page": {"page": 0, "size": 10}}

// ✅ 正确：分页从 1 开始
{"page": {"page": 1, "size": 10}}
```

### 参数类型错误

当看到 `type mismatch: expect string, actual number` 错误时，通常是因为枚举/状态字段未加 `json:",string"` tag。

**解决方案**：
- 前端发送字符串值：`{"status": "1"}` 而非 `{"status": 1}`
- 后端添加 tag：`Status int64 \`json:"status,string"\``

# 截图、显示层与触摸兼容排查

> 本文件是 [watcher-ui-network.md](watcher-ui-network.md) 的子文档，收录「截图崩溃、串口分片与跨页遮挡排查」和「SPD2010 在 IDF 6 下的纯读兼容」两节：字体行高与字幕视口、菜单布局与滚动、截图栈预算、RGB565、串口分片、top layer 与触摸 I²C 读兼容。

## 截图崩溃、串口分片与跨页遮挡排查

- 字体名中的字号不是实际行高。先从板型 CMake 选择和真实字体资源核对 `line_height`，
  再检查文字槽高度、内边距与圆屏安全区；Watcher 内置 30px 字体实际行高 43px，
  35px 状态栏及 40px 菜单文字槽会裁字。不要只把不同矩形排开就宣称可读。
  空角色标签须隐藏，不能以空字符串仍占一行挤压另一角色；长字幕保留触屏滚动。
  首段回复及停留尾部时的增量跟随，用户上滑阅读则保留位置；预览结束恢复最新回复。
  `test_watcher_subtitle_viewport.py` 编译执行生产视口函数与真实跟随表达式，覆盖空角色、
  首段/增量、人工阅读和预览切换并连续运行十次；几何用例先验证旧实现失败。
  最后使用本次固件截图及实际圆屏确认状态文字、菜单和长回复，主机替身不证明像素可见。
- 多行结果标题必须按真实排版高度安排列表，不能沿用单行标题的固定起点。
  `test_watcher_menu_layout.py` 链接实际 LVGL 与内置字体，执行生产页面创建和渲染；
  对绑定完成、换网完成、超时、取消及存储失败连续十次检查标题/列表不重叠、
  列表底边仍在圆屏安全区。缺少受管理依赖时明确跳过，不将跳过当作布局已验证。
  滚动视口高度按实际行高和主题行间距容纳整行，不能只保证当前焦点完整而露出半截邻行。
  用例还复用真实PageManager/焦点组，十轮遍历主菜单七个焦点及结果页；
  页面管理器须先于LVGL反初始化析构，不能用只换屏的替身隐藏焦点滚动或生命周期问题。
  正式构建关闭E2E时，Kconfig会省略依赖它的UDP诊断选项。门禁接受该项缺席或标准
  “未启用”注释，拒绝显式赋值及缺失配置文件，并继续检查实际ELF无诊断符号；
  用实际shell收尾片段覆盖上述情况，不能强求隐藏选项必须写出“未启用”行。
  同一真实LVGL用例还执行生产字幕布局、视口函数和跟随表达式：用多屏汉字长文
  检查首段滚到末尾、上滑位置不被后续增量改变、新用户字幕回顶及预览结束恢复尾部。
  字幕阅读再经生产触点读取、真实LVGL命中/惯性滚动回放十轮：向下拖动阅读旧文，
  增量保持该阅读位置，再向上拖至尾部恢复跟随；不能直接设置滚动坐标替代拖动。
  增量可能增加行数，相反方向同距离不保证回到尾部，使用有界重复拖动并检查实际余量。
  仅删除移动采样的负例必须失败，防止把点按当作滚动成功；它是测试故障注入，不是现场缺陷。
  这补足滚动调用替身的布局边界，但仍不能代替物理触屏拖动及LCD现场可读性。
  网络事务页的硬件验收仍需真实流程截图，不能为了采图改写设备已保存网络。
- 截图命令本身也须验收栈预算。若日志停在页面渲染开始，未到渲染结束便崩溃，
  先记录调用任务的栈余量和阶段，不因回溯落在调度器就直接改 FreeRTOS。
  Watcher 已复现默认 4KB 控制台栈不足：测试构建预留 12KB 后连续截图通过，
  正式构建保持原预算且不开放测试入口。换字体、页面或 LVGL 后仍需重新测余量。
- RGB565 字节序按 LVGL 输出和 JPEG 编码器合同核对；当前 RGB565_LE 入口不额外交换字节。
  用确定性红绿蓝像素执行生产捕获函数，不能只靠 JPEG 魔数验证颜色正确。
- 串口可在 END 前缀或传输 ID 中间分片；必须收齐完整结束行再校验并保存图片。
  对结束记录逐字节切分测试，覆盖超时、缺片、重复及崩溃标记；失败不保存半张图。
- 独立 top layer 会跨页面保留。主页主题与固定深色菜单不同，切页和换主题时都要重设
  状态栏配色；主页底部提示层在菜单隐藏、回主页恢复，避免时钟和通知压住菜单列表。
  回归真实主页、对话、菜单首尾项、预览和网络结果页；菜单聚焦末项时也须截图。
  同步检查活动/隐藏页字体生命周期，入口为 `test_watcher_font_lifetime.py`。

## SPD2010 在 IDF 6 下的纯读兼容

若启动日志出现 `i2c transmit buffer or size invalid`、SPD2010 `Read version failed`，
先检查 LCD I²C 读入口，不要直接判定接线错误。该驱动先单独写寄存器地址，
随后必须以 `lcd_cmd=-1` 纯读取；配置为零命令位、无控制阶段却传 `0`，会让 IDF 6
尝试零长度 `transmit_receive` 并返回参数错误。不要通过增加命令位发送额外寄存器字节。
Watcher 使用 `prepare_touch_i2c.py` 在构建目录生成单点适配，CMake 只替换该组件编译输入，
不修改受管理依赖；锚点或源数量变化须停止审查。`test_touch_i2c.py` 执行读调用表达式，
验证旧入口失败、新入口十次通过及依赖漂移；这仅证明调用合同，不能替代真实 I²C 验收。
真机还需核验驱动初始化成功、坐标/滚动、首页触摸入口及唤醒误触保护，不能只凭 OTA 成功。

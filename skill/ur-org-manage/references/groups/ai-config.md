# ai/config

> 该 group 共 7 个端点。

- `POST /api/v1/ai/config/info/create` [admin] 创建配置
- `POST /api/v1/ai/config/info/delete` [admin] 删除配置
- `POST /api/v1/ai/config/info/get-default` [admin] 获取默认配置
- `POST /api/v1/ai/config/info/get-list` [admin] 获取配置列表
- `POST /api/v1/ai/config/info/get-one` [admin] 获取配置详情
- `POST /api/v1/ai/config/info/test` [admin] 测试配置
- `POST /api/v1/ai/config/info/update` [admin] 更新配置

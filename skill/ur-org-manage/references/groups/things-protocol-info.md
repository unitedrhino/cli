# things/protocol/info

> 该 group 共 5 个端点。

- `POST /api/v1/things/protocol/info/create` [admin] 新增自定义协议
- `POST /api/v1/things/protocol/info/delete` [admin] 删除自定义协议
- `POST /api/v1/things/protocol/info/get-list` [admin] 获取自定义协议信息列表
- `POST /api/v1/things/protocol/info/get-one` [admin] 获取自定义协议详情
- `POST /api/v1/things/protocol/info/update` [admin] 更新自定义协议

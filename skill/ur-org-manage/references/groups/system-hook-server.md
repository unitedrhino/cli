# system/hook/server

> 该 group 共 5 个端点。

- `POST /api/v1/system/hook/server/create` [platform] 新增Hook服务
- `POST /api/v1/system/hook/server/delete` [platform] 删除Hook服务
- `POST /api/v1/system/hook/server/get-list` [platform] 获取Hook服务列表
- `POST /api/v1/system/hook/server/get-one` [platform] 获取Hook服务详情
- `POST /api/v1/system/hook/server/update` [platform] 更新Hook服务

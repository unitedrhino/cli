# ai/memory/debug

> 该 group 共 5 个端点。

- `POST /api/v1/ai/memory/debug/archives/get-list` [platform] 调试-归档记录列表
- `POST /api/v1/ai/memory/debug/dream-runs/get-list` [platform] 调试-Dream运行记录列表
- `POST /api/v1/ai/memory/debug/overview` [platform] 记忆调试总览
- `POST /api/v1/ai/memory/debug/pipeline-state/get-list` [platform] 调试-流水线状态列表
- `POST /api/v1/ai/memory/debug/traces/get-list` [platform] 调试-召回轨迹列表

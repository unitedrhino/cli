# v0.9.1 更新说明

修复临时下载目录与 CLI 安装目录位于不同文件系统时，升级因 invalid cross-device link 失败的问题。新二进制先在安装目录中完整暂存并关闭，再进行原子替换。复制失败时保留旧版，Windows 安装失败时恢复旧文件。

本版继续包含 v0.9.0 的组件目录搜索、内置图元搜索和详情查询。CLI、随包 Skills、独立 Skills ZIP、一次图案例及使用说明同步更新。

```bash
ur upgrade --version v0.9.1
ur --version
ur view component search --keyword 连线 --json
ur view component get-one --key TextCommon --json
ur view builtin-image search --keyword 圆形 --category electric --size 10 --json
ur view builtin-image get-one --id bi-electric-0952 --json
```

旧版首次跨盘升级若已报错，重新运行官方安装脚本可安装完整包，Linux/macOS 使用以下命令。

```bash
curl -fsSL https://doc.unitedrhino.com/cli/install.sh | UR_TAG=v0.9.1 bash
```

Windows 可在 PowerShell 使用官方 install.ps1，设置 `$env:UR_TAG="v0.9.1"` 指定版本。升级后重新打开 AI 会话加载新 Skills。

验证涵盖独立 tmpfs 到安装目录的真实跨文件系统替换、失败时旧版保留与暂存文件清理，以及组件搜索、图库查询和既有命令测试。正式发布按五平台 Harbor 下载、摘要、架构、版本元数据与 Skills 内容一致性验收。

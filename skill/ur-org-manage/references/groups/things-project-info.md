# things/project/info

> 该 group 共 5 个端点。

- `POST /api/v1/things/project/info/create` [admin] 新增项目
- `POST /api/v1/things/project/info/delete` [admin] 删除项目
- `POST /api/v1/things/project/info/get-list` [all] 获取项目列表
- `POST /api/v1/things/project/info/get-one` [all] 获取项目详情
- `POST /api/v1/things/project/info/update` [admin] 更新项目

# ai/agent-group

> 该 group 共 5 个端点。

- `POST /api/v1/ai/agent/group/create` [admin] 创建助手组
- `POST /api/v1/ai/agent/group/delete` [admin] 删除助手组
- `POST /api/v1/ai/agent/group/get-list` [admin] 获取助手组列表
- `POST /api/v1/ai/agent/group/get-one` [admin] 获取助手组详情
- `POST /api/v1/ai/agent/group/update` [admin] 更新助手组

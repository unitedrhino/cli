# ai/skill

> 该 group 共 8 个端点。

- `POST /api/v1/ai/skill/create` [admin] 创建技能
- `POST /api/v1/ai/skill/delete` [admin] 删除技能
- `POST /api/v1/ai/skill/download` [admin] 下载技能zip包
- `POST /api/v1/ai/skill/get-list` [admin] 获取技能列表
- `POST /api/v1/ai/skill/get-one` [admin] 获取技能详情
- `POST /api/v1/ai/skill/publish` [admin] 发布新版本
- `POST /api/v1/ai/skill/update` [admin] 更新技能
- `POST /api/v1/ai/skill/upload` [admin] 上传技能zip包

# system/mall/package

> 该 group 共 5 个端点。

- `POST /api/v1/system/mall/package/create` [platform] 创建套餐
- `POST /api/v1/system/mall/package/delete` [platform] 删除套餐
- `POST /api/v1/system/mall/package/get-list` [admin] 获取套餐列表
- `POST /api/v1/system/mall/package/get-one` [admin] 获取套餐详情
- `POST /api/v1/system/mall/package/update` [platform] 更新套餐

# things/protocol/config

> 该 group 共 5 个端点。

- `POST /api/v1/things/protocol/config/create` [admin] 创建协议配置
- `POST /api/v1/things/protocol/config/delete` [admin] 删除协议配置
- `POST /api/v1/things/protocol/config/get-list` [admin] 获取协议配置列表
- `POST /api/v1/things/protocol/config/get-one` [admin] 获取协议配置详情
- `POST /api/v1/things/protocol/config/update` [admin] 更新协议配置

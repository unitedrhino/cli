# system/dict/detail

> 该 group 共 5 个端点。

- `POST /api/v1/system/dict/detail/create` [platform] 添加字典详情
- `POST /api/v1/system/dict/detail/delete` [platform] 删除字典详情
- `POST /api/v1/system/dict/detail/get-list` [platform] 获取字典详情列表
- `POST /api/v1/system/dict/detail/get-one` [platform] 获取字典详情单个
- `POST /api/v1/system/dict/detail/update` [platform] 更新字典详情

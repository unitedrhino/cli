# system/notify/config

> 该 group 共 7 个端点。

- `POST /api/v1/system/notify/config/create` [platform] 添加通知配置
- `POST /api/v1/system/notify/config/delete` [platform] 删除通知配置
- `POST /api/v1/system/notify/config/get-list` [platform] 获取通知列表
- `POST /api/v1/system/notify/config/get-one` [platform] 获取通知详情
- `POST /api/v1/system/notify/config/send-test` [platform] 测试发送通知
- `POST /api/v1/system/notify/config/tree` [platform] 获取通知列表树
- `POST /api/v1/system/notify/config/update` [platform] 更新通知配置

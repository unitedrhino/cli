# system/notify/message/info

> 该 group 共 4 个端点。

- `POST /api/v1/system/notify/message/info/delete` [platform] 删除消息
- `POST /api/v1/system/notify/message/info/get-list` [platform] 获取消息列表
- `POST /api/v1/system/notify/message/info/send` [platform] 发送消息
- `POST /api/v1/system/notify/message/info/update` [platform] 更新消息

# things/product/schema

> 该 group 共 7 个端点。

- `POST /api/v1/things/product/schema/batch-create` [admin] 批量创建产品物模型
- `POST /api/v1/things/product/schema/create` [admin] 创建产品物模型
- `POST /api/v1/things/product/schema/delete` [admin] 删除产品物模型
- `POST /api/v1/things/product/schema/get-list` [admin] 获取产品物模型
- `POST /api/v1/things/product/schema/tsl-import` [admin] 导入产品物模型tsl
- `POST /api/v1/things/product/schema/tsl-read` [admin] 获取产品物模型tsl
- `POST /api/v1/things/product/schema/update` [admin] 更新产品物模型

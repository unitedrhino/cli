# system/dict/info

> 该 group 共 7 个端点。

- `POST /api/v1/system/dict/info/batch-export` [platform] 批量导出字典信息
- `POST /api/v1/system/dict/info/batch-import` [platform] 批量导入字典信息
- `POST /api/v1/system/dict/info/create` [platform] 添加字典信息
- `POST /api/v1/system/dict/info/delete` [platform] 删除字典信息
- `POST /api/v1/system/dict/info/get-list` [all] 获取字典信息列表
- `POST /api/v1/system/dict/info/get-one` [platform] 获取字典信息详情
- `POST /api/v1/system/dict/info/update` [platform] 更新字典信息

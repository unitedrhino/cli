# system/tenant/info

> 该 group 共 6 个端点。

- `POST /api/v1/system/tenant/info/create` [all] 添加租户
- `POST /api/v1/system/tenant/info/delete` [platform] 删除租户
- `POST /api/v1/system/tenant/info/get-list` [platform] 获取租户列表
- `POST /api/v1/system/tenant/info/get-one` [admin] 获取租户详情
- `POST /api/v1/system/tenant/info/transfer` [admin] 转让租户（仅租户所有者）
- `POST /api/v1/system/tenant/info/update` [admin] 更新租户

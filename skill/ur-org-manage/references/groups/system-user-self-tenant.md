# system/user/self/tenant

> 该 group 共 5 个端点。

- `POST /api/v1/system/user/self/tenant/delete` [all] 退出当前企业
- `POST /api/v1/system/user/self/tenant/get-list` [all] 获取用户所处的企业列表
- `POST /api/v1/system/user/self/tenant/get-one` [all] 获取当前用户在当前企业的详情
- `POST /api/v1/system/user/self/tenant/join` [all] 用户加入企业（通过邀请码、邮件或手机邀请）
- `POST /api/v1/system/user/self/tenant/update` [all] 更新当前用户在当前企业的信息

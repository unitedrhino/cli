# things/ota/module/info

> 该 group 共 5 个端点。

- `POST /api/v1/things/ota/module/info/create` [admin] 创建模块
- `POST /api/v1/things/ota/module/info/delete` [admin] 删除模块
- `POST /api/v1/things/ota/module/info/get-list` [admin] 获取模块列表
- `POST /api/v1/things/ota/module/info/get-one` [admin] 查询模块详情
- `POST /api/v1/things/ota/module/info/update` [admin] 更新模块

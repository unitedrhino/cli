# things/group/info

> 该 group 共 5 个端点。

- `POST /api/v1/things/group/info/create` [admin] 创建分组
- `POST /api/v1/things/group/info/delete` [admin] 删除分组
- `POST /api/v1/things/group/info/get-list` [admin] 获取分组列表
- `POST /api/v1/things/group/info/get-one` [admin] 获取分组详情信息
- `POST /api/v1/things/group/info/update` [admin] 更新分组信息

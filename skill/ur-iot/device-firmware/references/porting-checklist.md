# 新设备固件移植清单

本清单把平台合同与芯片实现分开。移植到不同芯片、RTOS 或网络模组时，平台 Topic 和
JSON 保持不变，HAL、存储、网络和 OTA 实现按目标 SDK 替换。

## 平台无关 HAL

- 唯一设备名来源：芯片 ID、出厂序列号或受控烧录值，格式稳定。
- 单调毫秒计时、Unix 秒/毫秒时间和可靠随机数。
- WiFi/以太网/蜂窝连接、DNS、TLS socket、CA 与主机名验证。
- 线程、队列、互斥、事件和 watchdog 喂狗边界。
- 安全存储：WiFi、DeviceSecret、待确认 OTA 状态；支持原子写和显式清空。
- 日志分级与敏感字段脱敏。

## MQTT 与协议层

- 支持动态注册临时 clientID、注册主题和 HMAC-SHA1/Base64。
- 支持正常 HMAC-SHA256 鉴权、keepalive、重连、订阅 ACK 和 QoS。
- JSON 解析有长度、类型、范围和缺失字段检查。
- `msgToken`、`actionID`、identifier 原样保留；重复请求具备幂等策略。
- 回调与 worker 解耦，所有共享状态有明确所有权。

## 配网与生命周期

- 明确首次启动、已有 WiFi、已有 DeviceSecret、恢复出厂和解绑后的状态转移。
- BLE/SoftAP 与主网络管理器互斥，所有退出路径释放资源。
- 动态注册失败、普通断网、明确鉴权失败采用不同恢复策略。
- 恢复出厂只清产品定义允许清除的分区，不破坏出厂校准、序列号或引导程序。

## OTA 能力

- 至少 A/B 两个应用分区，目标分区容纳最大镜像并保留元数据空间。
- SDK 支持镜像验证、设置启动分区、待验证状态和 rollback。
- 流式 HTTP 下载、实际长度和 MD5 校验，不依赖整包 RAM。
- OTA worker 不阻塞 MQTT；进度状态线程安全。
- 固件版本可在镜像内读取，并通过 `reportInfo` 上报。

## 构建与发布

- 工具链和容器按不可变版本/摘要固定。
- 构建时校验板型、Flash 大小、分区表、TLS、rollback 和所需网络组件。
- ProductSecret 仅在确需一型一密时安全注入；不能出现在 CI 日志和公共产物。
- 生成应用分区单文件、尺寸、SHA-256、MD5、版本和 Git SHA 清单。
- 自动扫描二进制和提交差异中的测试 SSID、密码、Token 与秘密。

## 移植完成判据

先通过纯软件测试向量（动态注册签名、MQTT 密码、JSON 编解码、OTA MD5），再完成
实机首次配网、重启自动上线、双向控制、断网恢复、全量 OTA、rollback、解绑重配和
真实断电。只完成 SDK 编译不算完成平台移植。

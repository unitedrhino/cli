# things/ota/firmware/info

> 该 group 共 5 个端点。

- `POST /api/v1/things/ota/firmware/info/create` [admin] 添加升级包
- `POST /api/v1/things/ota/firmware/info/delete` [admin] 删除升级包
- `POST /api/v1/things/ota/firmware/info/get-list` [admin] 升级包列表
- `POST /api/v1/things/ota/firmware/info/get-one` [admin] 查询升级包
- `POST /api/v1/things/ota/firmware/info/update` [admin] 修改升级包

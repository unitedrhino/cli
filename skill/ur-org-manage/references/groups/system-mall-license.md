# system/mall/license

> 该 group 共 5 个端点。

- `POST /api/v1/system/mall/license/batch-create` [platform] 批量创建授权码
- `POST /api/v1/system/mall/license/create` [platform] 创建授权码
- `POST /api/v1/system/mall/license/get-list` [admin] 授权码列表
- `POST /api/v1/system/mall/license/get-one` [admin] 授权码详情
- `POST /api/v1/system/mall/license/revoke` [platform] 撤销授权码

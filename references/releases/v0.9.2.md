# v0.9.2 更新说明

CLI 升级与独立 Skills 更新统一使用安装目录所在文件系统暂存、备份和替换，修复下载目录跨盘时 Skills 备份失败的问题。新技能完整复制成功后才移动旧目录，替换失败会回滚，回滚失败保留旧版备份并给出位置。CLI 已替换但 Skills 同步失败时返回明确失败状态，支持重新运行升级恢复。

包含 v0.9.0 的组件目录搜索、内置图元搜索和详情查询，以及 v0.9.1 的二进制原子替换修复。CLI、随包 Skills、独立 Skills ZIP、一次图案例和使用说明同步交付。

```bash
ur upgrade --version v0.9.2
ur --version
ur view component search --keyword 连线 --json
ur view component get-one --key TextCommon --json
ur view builtin-image search --keyword 圆形 --category electric --size 10 --json
ur view builtin-image get-one --id bi-electric-0952 --json
```

旧版首次跨盘升级已报错时，Linux/macOS 可重新运行官方安装脚本取得完整包，再安装 AI 指引。

```bash
curl -fsSL https://doc.unitedrhino.com/cli/install.sh | UR_TAG=v0.9.2 bash
ur skills install
```

Windows 使用官方 install.ps1，并设置 `$env:UR_TAG="v0.9.2"` 指定版本。升级后重开 AI 会话加载新技能。

验收覆盖跨文件系统二进制替换、首次与重复 Skills 同步、损坏来源时旧版保留、CLI 实际升级、独立 Skills 更新和五平台制品、版本、完整内容一致性。

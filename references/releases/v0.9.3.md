# v0.9.3：设备面板开发与 Skills

- 面板能力数量独立限制为 256 项，ZIP 文件数量仍限制为 100 个。
- 本地模拟读取包内 `.data/mock.json`；显式运动与复位合同决定模拟行为，不按字段名猜测，不调用真实设备。
- Skills 说明客户端安装、物模型合同、品类视觉与 Web/手机布局；明确 SDK 运行期模型与原生导入模型的区别。

## 升级与使用

```sh
ur upgrade --version v0.9.3
ur skills target detect
ur skills install --all
ur skills status
```

重开 AI 会话后读取 ur-product 面板指南。仅安装 CLI 不代表客户端已加载技能。普通属性写入保持原合同；复位型命令使用 completion=receipt 时须先确认宿主支持，不支持的旧宿主会拒绝请求，不自动重发。此版本不更改生产服务、设备协议或数据库。

完整品类方案通过面板库按需下载，随包只包含基础样板和开发规范。模拟截图仅证明预览，不代替真实设备验证。

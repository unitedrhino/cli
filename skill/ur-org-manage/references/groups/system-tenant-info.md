# system/tenant/info

> 该 group 共 6 个端点。

- `POST /api/v1/system/tenant/info/create` [all] 添加企业
- `POST /api/v1/system/tenant/info/delete` [platform] 删除企业
- `POST /api/v1/system/tenant/info/get-list` [platform] 获取企业列表
- `POST /api/v1/system/tenant/info/get-one` [admin] 获取企业详情
- `POST /api/v1/system/tenant/info/transfer` [admin] 转让企业（仅企业所有者）
- `POST /api/v1/system/tenant/info/update` [admin] 更新企业

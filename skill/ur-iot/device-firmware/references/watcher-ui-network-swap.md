# 官方客户端权限与本地换网事务

> 本文件是 [watcher-ui-network.md](watcher-ui-network.md) 的子文档，收录「官方客户端权限与配网绑定」和「本地换网事务与可选在线入口」两节：客户端权限策略、换网阶段与错误合同、`configureNetwork` 可选在线入口及 converge 工具。

## 官方客户端权限与配网绑定

当前换网仅涉及设备与小程序：不新增云端网络签名接口或 E6，保留 E5 v2。
官方小程序从既有设备查询取得真实项目，查询当前账号、项目拥有者及明确项目管理授权；
普通读写成员不放行，权限查询失败不发送凭据。此检查属于官方客户端策略，
不是 BLE 密码学鉴权；物理限时窗口中不能宣称阻止其他 BLE 客户端。手机需联网查询既有权限，
设备可离线；不下发 configureNetwork、不创建绑定 Token 来执行换网。

网络菜单分开“更换 Wi-Fi”和“配网并绑定”。后者二次确认默认取消，
独占启动复用 SDK Token 流程，候选不提前写正式列表；收到 `appBindToken code=200`
且仍有 IP 后提交网络。该回执只证明 Token 与设备关联，小程序随后调用绑定接口才完成归属。
提交前异常重启或 SDK 失败保留旧网络；手机后续绑定失败不会撤销已保存的新网络，
也不主动清密钥或解绑。云端绑定与本地保存不是分布式事务，云端已经成功后本地故障
不能自动回滚绑定；测试必须分别核对 Token 回执、手机绑定接口结果与 Wi-Fi 保存。
首页显式触摸菜单、音量/亮度触摸增减继续使用原页面代次、忙状态和唤醒保护。
以上新增能力仍需目标固件、Android/iOS 与真实断电验收，不拿旧固件结果代替。

回归增加双端 `network-permission-runtime.test.cjs`（拥有者、管理员、普通成员、
其他项目/用户、查询失败），保留 E2/E4 日志脱敏；不再运行撤销的签名向量测试。
`test_ur_network_ble.py` 执行实际绑定入口和候选路径，覆盖 SDK 失败、IP 丢失、
读取/提交失败及成功；`test_ur_network_transaction.py` 覆盖绑定受控启动和冷启动恢复。

## 本地换网事务与可选在线入口

换网保留正式 Wi-Fi 列表、DeviceSecret、所属项目和绑定；候选配置独立持久化。
BLE 配网独立启动，不与正常 WifiManager 并行初始化。OTA/相机忙时拒绝入口，
进入换网先关闭语音。在线行为先回执受理，再显示默认取消的物理确认页；离线可以本地进入。

| 合同 | 内容 |
|---|---|
| `configureNetwork` | 可选在线唤起行为，输入 `requestId` 为 16 位十六进制字符串，输出布尔 `Result`；本地菜单不依赖该行为 |
| 本地闭环 | 不新增状态属性、不等 MQTT 回执、不修改后端；已有 `networkConfigStatus` 不再作为前提，也不自动删除 |
| 阶段 | 0 空闲、1 已准备、2 BLE 等待、3 候选连接、6 提交、7 已保存、8 失败、9 待物理确认；4/5 为旧流程保留值 |
| 错误 | 0 无、1 重启中断、2 超时、3 取消、4 鉴权（旧流程保留）、5 网络、6 存储 |

BLE 等待最多 180 秒；取得 IP 后还须确认实际关联 SSID 与候选一致，
保存提交意图、写入并回读正式列表、持久化成功终态，然后才发送标准联网成功通知。
GATT 写完成、取得 IP 或阶段受理均不能直接显示成功。云端不可达不撤销已保存的新网络，
应单独显示云端离线。换网不清密钥、不动态注册；提交前取消、超时、异常启动恢复旧配置。
正式配置写入中断需先完成恢复并回读，恢复不确定时停止普通联网，不能丢失旧网络。

仅使用可选在线入口时，通过既有 API 查询行为、仅创建缺项、回读确认；冲突停止，不覆盖其他能力。
在包含 TASK-143 工具的 SaaS 仓库根目录：

```bash
python3 shell/converge-watcher-network.py --check \
  --expected-base-url '<当前环境地址>' --expected-tenant-code '<当前组织编码>'
# 目标及环境门禁通过、写操作获授权后，才将 --check 改为 --apply。
python3 shell/test-converge-watcher-network.py
```

工具当前限定 Product 8；其他产品不能照抄执行，应先核验并调整目标合同与测试。
`--check` 返回 1 表示缺项，2 表示检查失败；`--apply` 部分失败可幂等重跑，但不得忽略合同冲突。

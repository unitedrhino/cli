# 常见错误排查

## 登录失败 - 企业校验

登录时请求头 `tenant-code` 需与用户所属企业匹配：

| 场景 | 行为 |
|------|------|
| 用户属于企业，企业已绑定 App | 登录成功 |
| 用户属于企业，企业未绑定 App | ❌ "该企业未绑定该应用，无法登录" |
| 用户不属于企业，App 是 `client` 类型 | 自动注册到 App 所属企业 |
| 不带企业登录，用户有绑定该 App 的企业 | 登录成功 |
| 不带企业登录，用户无绑定该 App 的企业 | ❌ "您没有权限访问该应用" |

**解决**：先不带 `tenant-code` 登录，查看 `userInfo.tenants` 确认用户所属企业。

## 401 认证失败

| 原因 | 排查方法 | 解决方案 |
|------|----------|----------|
| `userID` 格式错误 | 检查是否为字符串格式 | 改为 `"userID": "12345"` |
| `accessSecret` 填错 | 检查大小写和完整 32 位 | 复制创建令牌时返回的完整 secret |
| JWT 已过期 | 检查 `exp` 字段 | 重新生成 JWT |
| 访问令牌过期 | Device Auth / JWT 模式 | 重新运行 `ur login` 或重新生成 JWT |

**Token 自动刷新**：CLI 调用 `ur api` 时，若遇到 401，会**自动使用保存的账号密码重新登录获取新 token**，保存后**自动重试原请求一次**。

## 403 权限不足

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| 权限不足 | 需要管理员权限 | 使用管理员账号或令牌 |
| 企业权限不足 | 需要 platform 权限 | 使用平台管理员账号 |
| 数据权限不足 | 无该项目/区域权限 | 申请数据权限或联系管理员 |
| 该企业未绑定该应用 | 企业未开通该 App | 联系平台管理员绑定应用 |

## 业务错误 (code != 200)

CLI 会在 stderr 输出友好错误提示，同时仍将完整响应输出到 stdout：

```
[错误] 业务返回 code=500: 数据不存在
```

| 错误码 | 常见原因 | 排查方法 |
|--------|----------|----------|
| 参数错误 | 必填字段缺失、格式错误 | 检查请求 body 格式 |
| 数据不存在 | ID 错误或已删除 | 先查询确认 ID 正确 |
| 数据已存在 | 唯一键冲突 | 检查名称/编码是否重复 |
| 状态错误 | 操作不允许当前状态 | 检查业务状态流转规则 |

## 连接问题

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| ECONNREFUSED | 服务未启动或端口错误 | 检查 `baseURL` 配置 |
| ETIMEDOUT | 网络超时 | 检查网络连通性或增加超时 |
| SSL 错误 | HTTPS 证书问题 | 检查证书或使用 HTTP |

## 问题反馈

当同一接口多次调用均返回异常、CLI 自动重试后仍然失败、或错误信息不明确时：

**控制台提交**（推荐）：访问控制台页面 `http://<host>:<port>/app/console/`，点击顶部「问题反馈」按钮。

**API 提交**：
```bash
ur api /api/v1/system/ops/feedback/create \
  --body '{
    "appID": "<当前应用ID>",
    "feedbackType": "usageProblem",
    "issueDesc": "描述遇到的问题",
    "contactInformation": "联系方式",
    "detail": "完整的 API 请求/响应、错误信息、操作步骤"
  }'
```

| 反馈类型 | 值 | 适用场景 |
|----------|-----|---------|
| 使用问题 | `usageProblem` | API 调用失败、功能异常 |
| 业务受损 | `businessImpaired` | 核心功能部分不可用 |
| 业务不可用 | `businessUnavailable` | 核心功能完全不可用 |

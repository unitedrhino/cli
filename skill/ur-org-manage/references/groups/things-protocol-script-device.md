# things/protocol/script/device

> 该 group 共 5 个端点。

- `POST /api/v1/things/protocol/script/device/create` [admin] 新增协议脚本设备
- `POST /api/v1/things/protocol/script/device/delete` [admin] 删除协议脚本设备
- `POST /api/v1/things/protocol/script/device/get-list` [admin] 获取协议脚本设备列表
- `POST /api/v1/things/protocol/script/device/get-one` [admin] 获取协议脚本设备详情
- `POST /api/v1/things/protocol/script/device/update` [admin] 更新协议脚本设备

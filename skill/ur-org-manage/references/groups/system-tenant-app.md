# system/tenant/app

> 该 group 共 5 个端点。

- `POST /api/v1/system/tenant/app/create` [all] 绑定租户应用
- `POST /api/v1/system/tenant/app/delete` [platform] 解绑租户应用
- `POST /api/v1/system/tenant/app/get-list` [admin] 获取租户应用列表
- `POST /api/v1/system/tenant/app/get-one` [platform] 获取应用信息
- `POST /api/v1/system/tenant/app/update` [platform] 更新租户应用

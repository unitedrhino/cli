# ur-user system/role/info

|------|------|------|------|
| POST | `/api/v1/system/role/info/create` | 添加角色 | admin |

| POST | `/api/v1/system/role/info/get-list` | 获取角色列表 | admin |
| POST | `/api/v1/system/role/info/update` | 更新角色 | admin |

# things/protocol/container

> 该 group 共 5 个端点。

- `POST /api/v1/things/protocol/container/install` [admin] 安装协议容器
- `POST /api/v1/things/protocol/container/status` [admin] 查询协议容器状态
- `POST /api/v1/things/protocol/container/stop` [admin] 停止协议容器
- `POST /api/v1/things/protocol/container/uninstall` [admin] 卸载协议容器
- `POST /api/v1/things/protocol/container/update` [admin] 更新协议容器

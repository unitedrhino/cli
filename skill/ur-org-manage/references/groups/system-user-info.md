# system/user/info

> 该 group 共 5 个端点。

- `POST /api/v1/system/user/info/create` [admin] 创建用户信息
- `POST /api/v1/system/user/info/delete` [admin] 刪除用户
- `POST /api/v1/system/user/info/get-list` [admin] 查询用户信息列表
- `POST /api/v1/system/user/info/get-one` [admin] 获取用户信息
- `POST /api/v1/system/user/info/update` [admin] 更新用户基本数据

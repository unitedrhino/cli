# 配网与绑定

配网只负责让设备安全获得网络、平台身份和可选绑定上下文。主网络管理器与临时
BLE/SoftAP 配网器必须串行拥有无线资源，不能同时初始化并争用事件循环或射频栈。

## 通用状态机

```text
读取持久化身份
├─ 有 WiFi → 连接 → 校时 → 注册/上线
└─ 无 WiFi → 启动 BLE 或 SoftAP
   → 接收并校验网络参数
   → 尝试联网 → 校时 → 动态注册
   → 可选绑定 → 原子保存 → 释放配网资源 → 重启/上线
```

失败路径必须区分：

- WiFi 参数错误：清本轮候选 WiFi，保留出厂身份，继续配网或回退 SoftAP。
- 注册失败：保留已验证 WiFi，按退避重试；不要把网络故障当作密码错误。
- 绑定失败：保持可重连/可重试，Token 未成功前不能提前停止广播。
- 总超时：释放 BLE/SoftAP、注销回调和定时器，再启动回退方案。

先写临时结构并验证成功，再原子更新正式 NVS；掉电不能留下“SSID 已保存但密码未
保存”或“DeviceSecret 只在内存中”的半状态。

## LLSync BLE 参考

采用 LLSync 的实现使用：

- Service UUID `FFF0`
- App 写 Characteristic `FFE1`
- 设备通知 Characteristic `FFE3`
- 协议版本 `0x02`

BlueZ 实机验收顺序是：扫描并连接 → 发现 FFF0/FFE1/FFE3 → 设备查询 → 设置 STA
模式 → 下发 WiFi → 请求连接 → 下发绑定 Token。具体二进制帧、校验和和分包规则
以固件中锁定版本的 LLSync SDK 为准，并用该版本抓包/协议工具验证；不要根据 UUID
自行编造帧。

外层配网等待时间必须长于 SDK 内层超时。绑定 Token 完成前继续广播并接受断线重连；
成功后停止广播、注销 GATT、释放控制器/Host 内存，再交给主网络管理器。若设备 OTA
走联犀 MQTT，全量关闭未验收的 LLSync BLE OTA，避免两个升级入口。

## SoftAP 回退

BLE 初始化失败、协议超时或硬件不支持 BLE 时，可进入固件已有的 SoftAP 配网。回退
不是并行启动：先完整释放 BLE，再启动 SoftAP。Web/API 输入必须限制长度、转义日志，
且不能在成功页面或串口回显 WiFi 密码。

## 绑定完成判据

1. 设备已用目标 WiFi 获得 IP 并完成校时。
2. 动态注册取得并持久化 DeviceSecret。
3. MQTT 正式连接和下行订阅成功。
4. `appBindToken` 回复成功，平台 Token 查询为 `status=2`。
5. 重启后无需再次配网即可上线。

只看到 BLE 写入成功或 WiFi 连接成功，都不能视为整个配网绑定流程完成。
